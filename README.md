# Luma

**Luma** is an Android TV application designed to provide a clean, fast and TV-friendly interface for accessing your own IPTV services.

## Download

The latest public version of Luma will be available from the **Releases** section of this repository.

> Only install APK files published through the official AversaHQ/LumaGlass repository.

## Features

- Android TV interface
- Live TV
- TV Guide / EPG
- Movies and series
- Sports interface
- Playlist support
- Remote-control navigation
- Search
- Media playback
- Update support

## Installation

1. Open the **Releases** section of this repository.
2. Download the latest Luma APK.
3. Transfer or download the APK to your Android TV device.
4. If Android asks, allow installation from unknown sources for the app you are using to open the APK.
5. Install Luma.
6. Open Luma and configure your own supported service or playlist.

## Requirements

- Android 6.0 (API 23) or later
- Android TV or a compatible Android-based TV/streaming device
- Internet connection
- Your own compatible IPTV service or playlist

## IPTV content

Luma is a media player/interface. **Luma does not provide, host, sell or include TV channels, movies, series, playlists or IPTV subscriptions.**

Users are responsible for supplying their own compatible service or playlist and for ensuring they have permission to access the content they use.
